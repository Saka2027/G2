# Mit Studieoverblik – G2

Mit Studieoverblik er en mobilapp udviklet i React Native med Expo. Appen hjælper studerende med at holde styr på opgaver og deadlines.

## Funktioner
- Opret opgaver med fag, navn og deadline.
- Marker opgaver som færdige.
- Slet opgaver.
- Gem opgaver lokalt med AsyncStorage.
- Naviger mellem fire skærme.

## Sådan starter du appen

1. Download projektet fra GitHub.
2. Åbn projektmappen i terminalen.
3. Kør `npm install`.
4. Kør `npx expo start`.
5. Scan QR-koden med Expo Go, eller tryk `w` for at åbne appen i browseren.
